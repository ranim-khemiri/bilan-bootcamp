# Point de contrôle : Bilan du Bootcamp

**Nom :** Ranim Khemiri
**Projet final :** Application de gestion des tâches (MERN)

## 1. Ma préparation pour la suite
Je me sens plutôt prête à commencer une nouvelle étape professionnelle.
Sur une échelle de 1 à 10, je me situe à **7/10**. J'ai acquis de solides
bases en développement web full-stack et j'ai construit un projet complet
avec la pile MERN. Il me reste à gagner en confiance et en expérience
sur des projets plus complexes, ce qui explique que je ne me mette pas à 10.

## 2. Compétences acquises
**Techniques**
- Développement backend avec Node.js et Express.js
- Base de données MongoDB et modélisation avec Mongoose
- Interface utilisateur avec React
- Création d'une API REST (CRUD)
- Utilisation de Git et GitHub
- HTML, CSS et JavaScript

**Transversales**
- Résolution de problèmes et débogage
- Autonomie et recherche de documentation
- Gestion de projet par phases
- Communication et travail en équipe

## 3. Ce dont je suis la plus fière
D'avoir conçu une application full-stack de A à Z : de la configuration
du backend jusqu'à l'interface React, en passant par la connexion à la
base de données.

## 4. Mes difficultés et axes d'amélioration
La configuration de l'environnement et la connexion entre le frontend et
le backend ont été les parties les plus délicates. Je souhaite approfondir
l'authentification, les tests et le déploiement d'une application.

## 5. Mes objectifs professionnels
Je vise un poste de développeuse web full-stack junior. Mes prochaines
étapes : construire mon portfolio, déployer mes projets, poursuivre mon
apprentissage et postuler à des offres.

## 6. Remarques pour l'instructeur
Merci pour votre accompagnement et vos conseils tout au long du Bootcamp.
Cette formation m'a permis de passer de la théorie à la réalisation
d'un vrai projet.
